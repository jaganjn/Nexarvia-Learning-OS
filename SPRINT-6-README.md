# Sprint 6 — Learning Twin & Capability Engine

## Goal
Convert learning activity and verified evidence into a transparent capability profile.

**Evidence → Mastery → Capability Level → Verification**

### Included
- Capability catalog
- Capability requirements
- Per-student capability profiles
- Mastery levels
- Evidence-to-capability linking
- Recency-weighted mastery aggregation
- Project/assessment evidence weighting
- Verified capability state
- Mastery snapshots
- Learning Twin API
- Capability recalculation API
- Student-facing Learning Twin page

### Important boundary
This sprint does not claim that a student is skilled merely because they completed content. Verification requires evidence and the verified state is kept separate from raw mastery.
