💡 CORE CONCEPT

State should live where it is needed.

Start with local state. Lift it only when multiple components genuinely need to share the same changing information. This keeps your interface easier to reason about and maintain.

Local stateOne component owns the value.
Shared stateMove ownership to a common parent.
Server stateData comes from an external source.
