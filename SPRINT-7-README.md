# Sprint 7 — Capability Passport & Career Engine

## Goal
Turn verified learning capability into a student-controlled career-facing profile.

**Verified capability → Passport → Opportunity matching → Student decision**

### Included
- Private/shareable/public capability passport
- Verified capability selection
- Student-controlled passport summary and visibility
- Career opportunity model
- Opportunity types: internship, job, project, scholarship, competition, freelance
- Capability requirement matching
- Match score with matched and missing capabilities
- Save/apply/dismiss opportunity state
- Opportunity authoring for admin/instructor
- Student-facing Capability Passport UI

### Safety boundary
The system never treats unverified learning activity as verified capability. Opportunity matching is a recommendation signal, not an eligibility or hiring decision.
