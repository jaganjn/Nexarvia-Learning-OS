# Sprint 3 — Practice & Assessment Engine

**Workflow:** Assessment → Attempt → Answer → Submit → Grade → Feedback → Evidence

Included:
- Persistent assessments and question bank
- Single/multiple choice, true/false, short/long text and numeric question types
- Publish state, passing score and attempt limits
- Persistent in-progress answers
- Automatic grading and result history
- Feedback
- Automatic assessment evidence
- Instructor/admin assessment and question creation APIs
- Student assessment API integration

AI/open-ended rubric grading and advanced adaptive difficulty belong to later AI/adaptive sprints.
