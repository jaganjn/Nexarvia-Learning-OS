CHALLENGE 02 · STATE MANAGEMENT

Build a shared course filter

15–20 min

Create a filter component that lets two sibling views respond to the same selected category. Keep state at the lowest common owner.

What you'll practiceState ownershipPropsEvent flowComponent composition
CourseFilter.jsx● Ready
function CourseFilter({ categories, selected, onChange }) {
  return (
    <select value={selected} onChange={e => onChange(e.target.value)}>
      {categories.map(category => (
        <option key={category}>{category}</option>
      ))}
    </select>
  );
}
