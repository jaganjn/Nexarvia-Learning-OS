# Nexarvia Learning OS 4.1 — Adaptive Core

This is a batched integration build on top of 4.0.

## Added
- Adaptive Learning Hub as an orchestration layer
- Next-best-action queue
- Explainable recommendation reasons
- Adaptive modality switching
- Learning-state signals from the shared prototype state
- Student control over recommendations
- AI/mentor fallback routes
- Preserved all previous modules and scroll behavior

## Product direction
The system should not merely recommend content. It should decide the most valuable next learning action from the student's current evidence, capability gaps and goals, while keeping the student in control.

This remains a front-end prototype. Production persistence, identity, authorization, AI inference, analytics pipelines and service integrations require a backend.
